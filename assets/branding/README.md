# OpenHaul icon

The master `openhaul-icon.png` is the original transparent PNG created with the built-in image generation tool. `openhaul-icon.ico` contains 16, 24, 32, 48, 64, 128 and 256 pixel PNG frames for Windows.

Website derivatives live in `apps/web/public`: the favicon, Apple touch icon and 32, 192 and 512 pixel PNGs. The client embeds the ICO for its window, header and tray; both Windows executable projects and Inno Setup also use it. Brand asset changes trigger the Windows build workflow.

## Generation prompt

Create a finished square app icon for OpenHaul, an open source Euro Truck Simulator 2 and American Truck Simulator trucking telemetry and convoy platform. A bold minimal geometric front-facing heavy truck cab merges with an open highway below, framed by a simple open hexagonal ring suggesting connection. Professional transport software identity. Strong single silhouette legible at favicon sizes. Flat graphic vector-like finish, crisp broad shapes, restrained emerald green #39e58c and mint #a6ffd0 on solid very dark forest #061b11 rounded square tile. Centered symmetrical composition, emblem fills 78 percent of canvas, generous safe inset. Transparent outside rounded square corners. No text, no letters, no gradients, no glow, no shadows, no fine detail, no mockup, no existing manufacturer logos. 1024x1024 single icon.
